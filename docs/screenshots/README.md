# Screenshots

Drop UI captures here and reference them from the README. Filenames are
deliberately short so they read well in markdown.

## Recommended captures

| File | What it shows |
|---|---|
| `console.png` | The Console — keyword input + pipeline strip + log |
| `wall.png` | A populated Wall — clusters of winning patterns |
| `history.png` | History list — past runs with platform badges |
| `settings.png` | Settings — Connections card after Check now |

Capture at 2× or 3× for crisp Retina renders, and at the page's natural
width so they don't squish on small screens.
